# Codex Task Request Template

Copy and edit this template when asking for a change.

```text
Goal:
- What should change?

Scope:
- Files or page area if known
- Must not change:

Acceptance criteria:
1.
2.
3.

Data/DB impact:
- Any Supabase table/policy/function change needed? (yes/no)

Language/UI:
- App text language:
- Assistant reply language:

Done when:
- Exact test steps that must pass
```

## Example

```text
Goal:
- In Sales Report, show receipt popup on click.

Scope:
- Owner dashboard only
- Must not change HQ pages

Acceptance criteria:
1. Clicking receipt opens modal.
2. ESC closes modal.
3. No console error.

Data/DB impact:
- no

Language/UI:
- App text language: English
- Assistant reply language: Korean

Done when:
- Tested in Preview URL and confirmed on one sample sale
```
